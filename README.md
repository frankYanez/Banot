## 🖥️ Instalación y Ejecución

### Opción 1: Abrir Directamente (Más Fácil)
1. **Descargar el proyecto**: Todos los archivos están listos
2. **Abrir index.html**: Simplemente doble-click en `index.html`
3. **¡Listo!**: La web se abrirá en tu navegador

### Opción 2: Servidor Web Local
```bash
# Navegar al directorio
cd /workspace

# Iniciar servidor HTTP simple
python -m http.server 8000

# O usar Node.js (si está disponible)
npx serve .

# Abrir en navegador
# http://localhost:8000
```

### Opción 3: Deployment en Web
1. **Subir archivos** a cualquier hosting (Netlify, Vercel, GitHub Pages)
2. **index.html** funciona inmediatamente
3. **Imágenes** en carpeta `imgs/` se cargarán automáticamente

## 🔧 Personalización

### Cambiar Colores
Editar las variables CSS en `:root`:
```css
:root {
    --gold-light: #FFD700;
    --gold-base: #F5B82E;
    --gold-dark: #B8860B;
    /* ... más variables */
}
```

### Modificar Animaciones
Las animaciones están en las secciones `@keyframes` del CSS.

### Añadir Contenido
El contenido está en el HTML. Editar directamente para cambiar:
- Textos y títulos
- Enlaces y navegación
- Imágenes (reemplazar en carpeta `imgs/`)

## 🚀 Deployment

### GitHub Pages
1. Subir proyecto a GitHub
2. Activar GitHub Pages en configuración
3. Seleccionar branch `main` y carpeta `/`
4. Tu web estará en `https://tu-usuario.github.io/tu-repositorio`

### Netlify
1. Arrastra y suelta la carpeta del proyecto
2. Netlify automáticamente detecta que es un sitio estático
3. Te dará una URL automática

### Vercel
1. Conectar tu repositorio Git
2. Vercel detecta automáticamente sitios estáticos
3. Deploy automático en cada push

### Hosting Tradicional
- Sube todos los archivos a tu servidor web
- Asegúrate de que `index.html` esté en la raíz
- Las imágenes se cargarán automáticamente
